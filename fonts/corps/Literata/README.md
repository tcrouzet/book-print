## Binary provenance

Imported from the user-provided polices-complet.zip archive. Font bytes are copied unchanged. These files use TrueType-flavoured OpenType data (signature 0x00010000) despite their .otf extension. The upstream family links identify the font projects; the archive does not provide an exact upstream download URL for each supplied binary.

For EPUB body text, Auto remains the default so the reading device can choose its font. Importing this family does not assign it to any project.
